## 🎲 Mini Ludo Game

A fun mini version of Ludo implemented using pure JavaScript.

### ✨ Features
- Dice roll with animation 🎲
- Start only on rolling a 6
- Token movement across cells
- Exact roll required to reach HOME
- Animated token movement
- Separate HOME cell
- Clean, game-like UI with animated background
